# OpenWorld — UE 5.6 / Windows

**Статус: исходная техническая основа в разработке. Не готовая игра и не подтверждённый playable vertical slice.**

В текущей среде нет Unreal Engine, Windows SDK, 3D-контента и доступа к Windows build runner. Компиляция Unreal Header Tool / C++, запуск, FPS и Windows packaging пока НЕ проверены. Исходный релиз не содержит `.exe`. Не считайте тег или зелёную проверку исходников подтверждением работоспособности игры.

Цель: оригинальная single-player open-world игра для Windows, с серверной авторитетностью игровых операций и возможностью дальнейшего развития multiplayer. UE 5.6, C++, Chaos Vehicles; игровые ассеты и Blueprints создаются/импортируются в Unreal Editor.

Инструкции по сборке, точный состав и границы реализации будут добавлены вместе с системами проекта.
